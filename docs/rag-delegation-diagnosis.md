## 修复约束与验收

- 用户原文作为意图和机构范围的依据，协调器 query 只能辅助定位知识子任务。
- 不把委派标签和重复拼接文本送入嵌入、关键词及重排服务。
- 本系统问题仍隔离外部馆规；有依据的否定规则可以回答，无依据继续拒答。
- 多轮改写只作检索输入，不替换用户问题；保持预算、来源及发布版本校验。
- 先加入能复现上述缺陷的行为测试，再实现并执行相关测试、全量后端和离线 Harness。
- 真实模型复验另存报告；新增题明确标记代理辅助编写，语义正确性保留待人工状态。

人工审核使用原有逐题报告及报告哈希绑定的模板，不由开发代理填写人工判断。
审核工作副本、导出方法和人工检查要求见 [官方资料验收指南](library-acceptance.md#知识委派修复与人工审核入口2026-10-18)。
