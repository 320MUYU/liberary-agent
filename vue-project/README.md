# 阅见 · 图书馆学习空间预约前端

基于 Vue 3、Vite、Vue Router 与 Element Plus 实现，连接仓库中的 FastAPI 后端。

## 已实现页面

- 概览：开放空间、近期预约和真实预约时长统计
- 学习空间：搜索、类型筛选、开放状态、设施信息与预约入口
- 我的预约：状态统计、记录筛选、取消预约与新建预约
- AI 空间助手：基于 DeepSeek 的预约规则与空间需求对话
- 管理后台：读者、空间、设施和预约审核
- 预约弹窗：学习空间、日期、时间、人数、用途及补充需求
- 桌面端与移动端响应式布局

## 运行项目

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 数据说明

空间、设施、用户和预约数据均来自 FastAPI 接口。浏览器只缓存 JWT 与当前用户基本信息。

AI 已接入 LangChain 与 DeepSeek，但尚未实现 RAG，也不能读取实时业务数据。知识库检索、来源引用和实时空间查询属于后续工作。
